# 🔐 Random Password Generator

A simple Python project that generates a random password based on the length entered by the user.

## 📌 Project Overview

This project is developed as **Project 3 – Random Password Generator** for the DecodeLabs Python Programming training.

The program uses Python's built-in `random` and `string` modules to generate a random password containing letters and numbers.

## ✨ Features

* 🔢 Allows the user to choose the password length
* 🔤 Generates uppercase and lowercase letters
* 🔢 Includes numbers
* 🎲 Generates a random password
* 🐍 Uses Python built-in modules

## 🛠️ Technologies Used

* Python
* `random` module
* `string` module

## 🚀 How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file:

```bash
python password_generator.py
```

5. Enter the required password length when prompted.

## 💻 Example

```text
Enter password length: 8
Generated Password: k7Pq2Lm9
```
